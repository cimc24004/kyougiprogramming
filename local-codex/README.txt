AlgoDojo+ / Codex Sol 6.1 接続プログラム（Windows）

API キーは不要です。PC にある Codex CLI の ChatGPT ログインを使用します。
Codex の利用上限は、ご自身の ChatGPT 契約・アカウントに従います。

使い方
1. ZIP を展開します（ZIP の中から直接実行しないでください）。
2. Node.js と Codex CLI がインストール済みであることを確認します。
   ターミナルで codex login status を実行し、ChatGPT にログイン済みか確認できます。
3. Start.cmd をダブルクリックし、そのウィンドウを開いたままにします。
4. https://algodojo-plus.kuroonrails.chatgpt.site を開きます。
5. 問題の「AI に解説・質問」を開き、「Sol 6.1 に質問する」を押します。
   ブラウザーにこの PC への接続の確認が出た場合は、許可してください。
6. 回答が同じ画面に表示されます。そのまま続けて質問できます。

止めるとき
Start.cmd のウィンドウで Ctrl+C を押します。
バックグラウンドで起動した場合は、PowerShell の Stop.ps1 でも停止できます。
PC の再起動後は Start.cmd をもう一度開いてください。

接続の範囲
127.0.0.1:49173 にのみ待ち受けます。外部公開はしません。
上記 AlgoDojo+ サイトからのみ、質問と回答の受け渡しを許可します。
モデルは gpt-6.1-sol に固定し、Codex のシェル・ブラウザー・アプリ・Web 検索などは無効にします。
回答生成は読み取り専用・一時セッションで行います。サイトにはログイン情報を渡しません。
問題、コード、入力、実行結果、質問、直近の会話を Codex に送ります。
会話は開いているサイト画面のメモリー内に保持され、再読み込みで消えます。
質問内容や回答をこのプログラムのログファイルには保存しません。

うまくいかないとき
・「接続できない」: Start.cmd の起動とブラウザーのこの PC への接続許可を確認してください。
・「既に起動中」: 接続プログラムは 1 つだけ開いてください。
・Codex のエラー: codex login status でログインを確認し、Codex の利用上限や接続を確認してください。
・解説には誤りが含まれる場合があります。コードは問題ページのテストでも確認してください。
